## Limits to disclose

The free account does not provide a continuously running separate worker. The API's minute reconciliation loop runs only while its web process is active; host idling or recycling interrupts retries and delayed-alert processing. This is unacceptable for clinical monitoring and must be shown as a research-demo limitation. The account has a small shared resource quota and short backup retention. Keep real patient data, live wearable credentials and clinical alerting off this host. If the dependency install, memory, WebSocket or database checks fail on the Free account, do **not** silently switch to a paid tier; continue the demo locally while evaluating a different no-card host.
