This redesign did not change authorisation rules or database schema. Protected routes retain their role gates; backend access control remains the security boundary. A prior contrast failure in the new views was fixed before the passing rerun. This is automated coverage of mocked API fixtures, not a live-provider or multi-user acceptance test.
